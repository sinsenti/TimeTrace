Shortcuts & recording help

Outside editors: Alt+Shift+1–9 selects; Alt+Shift+Enter starts the picked task; Alt+Shift+P pauses/resumes; Alt+Shift+S stops; Alt+Shift+F searches. In Task to time, use ↑/↓ to choose and Enter to start; Tab only moves focus. Close matches require explicit selection. Filter activities only narrows priority groups; Enter never starts there. Search history & plans filters the ledger and saved-history export independently. Clock ±5 applies directly after a one-time explanation. Adjust time keeps Preview and Apply for full interval edits. Invalid quick adjustments are refused, never clamped.

History reads intervals intersecting the local day, grouped by local start day. Totals retain their labeled start-date cohort. Activity discovery shows up to 20 results, grouped by priority; filter by priority or search for more tasks. Schedule badges do not change priority order. Notes filtering searches saved entry notes and scheduled-session plan notes, not task descriptions or live timer notes. More combinations are in Tasks filters and Statistics.

Carry-ins belong to their local start day, not this day's export. Export uses a bounded saved-work start-day view; plans and live timers are never eligible.

Entry note belongs to tracked work: Save keeps the note on the eligible timer interval; Stop & record carries it into saved history. Saved entries have their own notes. Task descriptions and plan notes remain separate. Discard my changes only reloads the saved note; it does not discard tracked time.
