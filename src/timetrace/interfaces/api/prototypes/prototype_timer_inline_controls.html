What this proposes

  • Immediate confirmation: Start returns to Today, selects the timer, scrolls it into view and highlights it. Other timers keep running.
  • Description belongs to this work: “Writing” is the task; “Draft the introduction” describes this particular work entry. Editing that note does not rename the task or rewrite earlier work.
  • Calendar shows evidence: a dashed live block while recording; saved recorded blocks after Stop. Planned time remains a separate column. Paused gaps are not recorded work.
  • Edit task: change the shared title, description, category and estimate without stopping the timer. This is a limited mock of the normal task editor, not a replacement.
  • Quick correction: +5 min adds credited work by moving this running segment’s start earlier; −5 min removes work by moving it later. Buttons apply immediately with visible feedback. Invalid corrections are refused, not silently clamped. Paused timers require Resume in this prototype.
  • Adjust time: preview an earlier/later start. This prototype edits only the current running segment; it never rewrites earlier paused segments or other timers.
  • No implied completion: stopping records work; it does not complete the task.

Timer controls, work notes, limited task editing and start-time correction are interactive.
