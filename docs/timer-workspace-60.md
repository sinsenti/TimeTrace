## Engineering decisions (recorded before their implementation)

- Pins use device-local localStorage `timetrace.workspace.pins.v1`: an ordered unique array of task UUIDs, in explicit insertion order. Unpin/re-pin appends. No task/work creation, account or cloud model. Resolve labels/availability from fresh task knowledge; missing/stale metadata disables Start. Storage errors are visible and do not claim successful persistence.
- Selection uses unfinished timer identity, independent of state. Start ACK selects its returned timer before display refresh unless a newer explicit selection supersedes it. Selection sends no write. Normal Starts on other pages navigate to `/agenda-view?timer=...` only if no newer interaction or dirty editor/modal intervenes; an explicit selected-workspace link remains available. On Agenda, current card precedes the reused unfinished-controller region and plan context. Dirty drafts are retained; asynchronous polling does not focus the card.
- Keyboard: Alt+Shift+1–9 selects unfinished timers in displayed order; Alt+Shift+Enter starts the task in the shared picker (empty means taskless); Alt+Shift+P pauses/resumes selected; Alt+Shift+S stops selected; Alt+Shift+F focuses search. No all-timer fallback. Before wiring, collision review covered included utils (Escape), timer_control (Escape idle review), task_modal (Tab/Escape), settings (typing/modifier guards) and AI assistant (Ctrl+Shift+A); none claims these chords. vim_engine is not included on Agenda. Typing, contenteditable, open dialog/Assistant and composition guards apply. Browser/OS-reserved bindings can still intercept chords; visible controls remain primary.
- Task discovery reuses `/api/tasks`, adding optional `title_contains`, `tag_contains` and `limit` (1–200). Existing callers/defaults are unchanged. UI asks for 50; SQL bounds materialization in stable UUID order before existing display sorting. Literal contains matching escapes SQL wildcard characters. History filters apply to the existing bounded daily Agenda read, with task/tag/work-note criteria. Cross-day and advanced combinations are explicitly directed to existing Tasks/Statistics rather than invented query semantics. Daily reads intersect the day; groups use each record's local start date. Union totals retain their explicitly labeled start-date cohort.
- History groups by `[local start day, task UUID/null, kind]`, never title. Every raw interval remains separately inspectable, with description, provenance and timestamps. Taskless and uncertain legacy records remain labeled; no raw aggregation/rewrite. Start again sends only task identity, not old timestamps, note or scheduled association. Same-task unfinished selection remains authoritative (including paused/frozen state).

## Current work-note contract (owner-confirmed)

Owner decision A: Pause → edit note → Stop records the edited description on the latest eligible uncommitted interval closed by that manual Pause, without resuming, committing or changing coverage. Older, idle-claimed and already-recorded descriptions stay unchanged. [Engineering contract comment](https://github.com/sinsenti/TimeTrace/issues/60#issuecomment-7100040035).

`POST /timers/{id}/note` extends the existing operation ID, expected timer revision and durable DB/file intent/receipt reconciliation protocol. Running edits update only the open description. Paused requests additionally supply `expected_note_segment_id`, matching persisted `manual_pause_note_segment_id`. Manual Pause establishes that pointer from the newly closed interval identity; resume, split, stop and idle resolution invalidate it. Missing/mismatched/ineligible targets refuse, with no array-tail fallback. Recovered older paused files without a pointer refuse until explicit lifecycle action establishes an eligible interval. Unresolved idle retains the existing refusal boundary. Existing actions preserve their pre-note canonical payload hashes for outstanding receipts.

Task/association snapshots, intervals, plans and recorded rows are unchanged. Browser drafts retain their captured revision/target through polling and selection; their own ACK advances their checkpoint before display reads, preserving later typing. Stop refuses an unsaved current-note draft until Save or explicit Use current saved note. `PATCH /recorded-work/{id}/note` is a separate revision-checked saved-note path: timestamps, association, provenance and review/rating identity are preserved. Failed/uncertain writes retain drafts; recovery refreshes read only. Task editing uses the existing full modal/validation/completion-policy flow, not a partial form. Timer labels read current task metadata without changing timer revisions or work coverage.

## Correction integration boundary (#61)

`[data-timer-correction-clock]` marks the clock beside which reviewed B-style circular five-minute controls can be mounted. `[data-timer-correction-actions]` marks the single wrapping Edit task / Pause-Resume / Stop & record action row for future Adjust time. No enabled/fake correction controls ship here. #61 supplies its durable correction interface, previews, bounds and final wiring. Original/current plans are not correction targets.
